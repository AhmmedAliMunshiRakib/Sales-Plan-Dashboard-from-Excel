# Sales-Plan-Dashboard
A professional Sales Plan Dashboard built entirely in Microsoft Excel, showcasing dynamic visualizations, automated insights, and an organized reporting view for decision‑makers. This project is designed to highlight my capabilities in Excel‑based data analysis, dashboard creation, and KPI reporting.

 ## Project Overview

This project analyzes sales performance and presents key business indicators through an interactive Excel dashboard. The dashboard is built using:

PivotTables

PivotCharts

Power Pivot

Power Query

Slicers & Filters

Dynamic ranges & formatting

It allows users to explore sales trends, compare plan vs. actual performance, and visualize key insights.

Data Cleaning

PivotTables & PivotCharts

Excel Formulas (SUM, COUNT, IF, etc)

Dashboard UI Design

KPI Tracking & Reporting
